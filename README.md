# GHOST CHAT BOX

**GHOST CHAT BOX** is a dark-mode AI chat application designed for a clean, responsive and engaging conversation experience.

The app features four conversation modes, allowing users to interact with the AI in different ways depending on what they need.

### Features

- Dark-themed interface.
- Four conversation modes.
- AI-powered conversations.
- Local conversation history.
- Responsive design for desktop and mobile.
- Simple and intuitive chat experience.

GHOST CHAT BOX brings AI conversations into one place, with a focus on usability, flexibility and a distinctive dark interface.
